# Quem Sou Eu?

Página pessoal de apresentação feita em **HTML e CSS** como projeto escolar. Nela eu me apresento, mostro minhas redes sociais e explico o que gosto e por quê.

## Sobre o projeto

O site é uma página única que reúne:

- Foto de perfil redonda e título da página
- Dois parágrafos de apresentação pessoal
- Ícones com links para Instagram, Spotify e YouTube
- Uma tabela "O que eu gosto e por quê?" com as minhas preferências (futebol, tecnologia e música)
- Favicon personalizado na aba do navegador

## Tecnologias usadas

- **HTML5**: estrutura da página (títulos, parágrafos, imagens, lista e tabela)
- **CSS3**: estilização (cores, centralização, `flexbox` nos ícones, bordas e imagem arredondada)

## Como rodar

1. Baixe ou clone o repositório:
   ```bash
   git clone https://github.com/magofino/quem_sou_eu.git
   ```
2. Entre na pasta `QuemSouEu`.
3. Abra o arquivo `index.html` no seu navegador (dois cliques ou botão direito → *Abrir com* → navegador).

Não precisa instalar nada nem ter internet para ver a página, só para os links das redes sociais funcionarem.
